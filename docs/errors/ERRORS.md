# REGISTRE D'ERRORS I SOLUCIONS — CampoPro

**Propòsit**:
Aquest fitxer és el registre central per al seguiment i resolució d'errors. L'objectiu és l'aprenentatge automàtic i col·laboratiu entre els agents per evitar repetir els mateixos errors al llarg del desenvolupament del projecte.

**Protocol d'Actuació**:
1. Comprova aquest fitxer ABANS d'implementar una solució a un error desconegut per si ja ha estat resolt prèviament.
2. Després de solucionar un error de forma satisfactòria, documenta'l aquí immediatament.
3. Si un error és recurrent o sistemàtic, escala'l a una revisió d'arquitectura.
